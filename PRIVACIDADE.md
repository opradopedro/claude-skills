# Política de Privacidade — Radar GTA 6 (YouTube)

Última atualização: 21 de outubro de 2026

O app "Radar GTA 6 - YT" é uma ferramenta de uso pessoal do dono do canal Radar GTA VI Brasil (https://youtube.com/@radargtavibrasil). Ele serve só para enviar os vídeos do próprio canal ao YouTube de forma automática.

## Quais dados o app usa

- Usa a permissão `youtube.upload` apenas para publicar vídeos no canal do próprio dono.
- Não lê, coleta, vende ou compartilha dados de outras pessoas.
- As credenciais de acesso ficam guardadas em variáveis de ambiente privadas, nunca em código público.

## Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a [Política de dados do usuário dos serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.

## Como revogar o acesso

O acesso pode ser removido a qualquer momento em https://myaccount.google.com/permissions.
